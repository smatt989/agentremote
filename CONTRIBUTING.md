# Contributing

Thanks for helping. Bug reports, fixes and small features are all welcome.

## Before you start

- **Bugs:** open an issue with the Mac app version (shown at the bottom of the Agent Remote window), the client (iPhone or desktop) and its build, what you did, and what happened. Leave out conversation content and tokens.
- **Features:** open an issue first to describe the problem it solves, so we can agree on the approach before you write it.
- **Security issues:** do not open a public issue; see [SECURITY.md](SECURITY.md).

## Pull requests

1. Fork the repository and branch from `main`.
2. Keep each pull request to one change, and match the style of the code around it.
3. Add or update tests for behavior you change, and run `npm test` (Node 24+). For app changes, build the affected Xcode target.
4. Describe what changed and how you tested it.

The maintainer reviews and merges pull requests. By contributing, you agree that your contribution is licensed under the [MIT License](LICENSE).
