# Security

Agent Remote lets paired devices direct coding agents with full access to a Mac, so security reports matter a lot.

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button on the repository's Security tab, not in a public issue. Include the affected component (Mac app, service, relay, iPhone or desktop client), the version, and steps to reproduce.

You should get a reply within a few days. Please give us a reasonable chance to ship a fix before disclosing the issue publicly.

The design and threat model are described in [docs/architecture-and-security.md](docs/architecture-and-security.md).
